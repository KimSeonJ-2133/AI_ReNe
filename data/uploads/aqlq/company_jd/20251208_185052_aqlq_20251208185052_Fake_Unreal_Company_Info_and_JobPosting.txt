회사 정보 및 구인 공고 (가상 언리얼 엔진 기반 게임 개발사)

1. 회사 개요

-   회사명: 헤일로 인터랙티브(Halo Interactive)
-   설립: 2018년
-   위치: 서울 강남구 테크밸리
-   직원 수: 45명
-   주요 엔진: Unreal Engine 5
-   주요 사업:
    -   실시간 멀티플레이어 게임 개발
    -   메타버스 기반 가상 오피스 플랫폼 연구
    -   게임 내 실시간 스트리밍/네트워크 기술 개발
-   회사 분위기:
    -   소규모 정예 조직
    -   기술 중심의 의사결정 문화
    -   자율 출퇴근제 및 원격 근무 지원

2. 현재 개발 중인 프로젝트

프로젝트명: Project AURORA

-   장르: 1인칭 액션 어드벤처
-   엔진: Unreal Engine 5.4
-   주요 특징:
    -   고품질 Lumen 글로벌 조명 기술 사용
    -   Chaos Physics 기반 파괴 시스템 구현
    -   온라인 협동 멀티플레이 지원
    -   실시간 AI Behavior Tree + EQS 활용

프로젝트명: Virtual Expo

-   Unreal 기반 가상 박람회 플랫폼
-   네트워크 기반 음성/화면 공유 기능
-   기업–유저 간 커뮤니케이션 시스템 구현

3. 회사가 찾는 인재상

-   언리얼 엔진 기반 프로젝트 경험 보유
-   C++ 기반 게임플레이 시스템 작성 능력
-   Blueprint와 C++을 혼합한 개발 경험
-   멀티플레이어 또는 네트워크 기능에 관심이 있는 개발자
-   문제 해결 능력, 논리적 사고, 원활한 소통 능력
-   스스로 학습하고 기술적 확장을 즐기는 사람

4. 구인 포지션: 언리얼 엔진 게임플레이 프로그래머 (Junior ~ Mid)

담당 업무

-   언리얼 엔진 기반 게임플레이 기능 개발
-   캐릭터, 무기, 전투, 상호작용 시스템 구현
-   UI/UX 시스템 개발(UMG 기반)
-   멀티플레이/Replication 기능 구현
-   성능 최적화 및 디버깅
-   디자이너/아티스트와 협업하여 콘텐츠 구현

자격 요건

-   Unreal Engine 사용 경험(개인/팀/학원 프로젝트 포함)
-   C++ 문법 및 객체지향 프로그래밍 이해
-   Unreal Actor/Component/Controller/GameMode 구조 이해
-   Blueprint 사용 능력
-   기본 Git 사용 가능

우대 사항

-   언리얼 엔진 멀티플레이어 프로젝트 경험
-   HTTP, WebSocket, Backend API 연동 경험
-   비동기 로직 구현 경험
-   AI Behavior Tree 경험
-   온라인 게임 서비스 경험(정식/검수/CBT 등)
