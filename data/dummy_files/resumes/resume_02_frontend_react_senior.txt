- 역할: 프론트엔드 리드
- 기술: Next.js 13, TypeScript, TailwindCSS, React Query

[상세 내용]
1. SSR/ISR 도입을 통한 SEO 최적화

   - 상품 상세 페이지에 ISR(Incremental Static Regeneration)을 적용하여 빌드 시간 단축 및 최신 데이터 제공.
   - 검색 엔진 노출 수 200% 증가.

2. 웹 성능 최적화 (Core Web Vitals)
   - LCP(Largest Contentful Paint) 개선을 위해 이미지 최적화(Next/Image) 및 폰트 프리로딩 적용.
   - CLS(Cumulative Layout Shift) 방지를 위해 스켈레톤 UI 및 고정 사이즈 컨테이너 적용.
   - Lighthouse 성능 점수 40점 -> 95점 달성.
